关于 LY2U SecWatch

LY2U SecWatch 汇总公开的漏洞情报，并提供一个只读的扫描器，帮助 VPS 和自建服务器的管理员回答三个问题：我的机器受不受影响？该升级到哪个版本？先修哪个？

本站和扫描器的全部代码在 github.com/ly2u/sec 开源，采用 Apache-2.0 许可证。

数据来源

  • CVE Program（cvelistV5）：漏洞描述、CVSS 评分、受影响版本，含 CISA 的 Vulnrichment 补充数据。
  • CISA KEV：已确认被在野利用的漏洞目录。
  • FIRST EPSS：漏洞在未来 30 天内被利用的概率估计。
  • OSV：Debian、Ubuntu、Alpine、Rocky Linux、AlmaLinux 的安全公告与修复版本。
  • Node.js Security WG：Node.js 自身及其内置依赖的漏洞。

各来源的许可与署名要求见仓库中的 THIRD_PARTY_NOTICES.md。本站不修改原始数据的含义；如有出入，以原始来源为准。

局限

漏洞数据只覆盖已公开、已编号的问题。0day、未分配编号的问题、以及数据源没有覆盖的软件，本站和扫描器都无法发现。“未列出”不等于“安全”。
