报告安全问题

如果你发现本站、扫描器或数据包签名流程中的安全问题，请不要在公开的 Issue 中报告。

请通过 GitHub 的私密漏洞报告提交：github.com/ly2u/sec/security/advisories/new。

报告中请尽量包含：受影响的组件和版本、复现步骤、你认为的影响。我们会在确认后尽快修复，并在修复发布后致谢（如你愿意）。

数据本身的错误（例如某个漏洞的受影响版本不对）不属于安全问题，欢迎直接在 Issues 中反馈。

发布签名

扫描器发布包和漏洞数据包使用两把不同的 minisign 密钥签名：

  • 发布包：release-signing.pub
  • 数据包：bundle-signing.pub（内置在扫描器中）
